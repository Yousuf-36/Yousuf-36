01 / ENGINEERING PROFILE

I build backend services and AI-integrated applications, with a focus on the parts that make software dependable: API boundaries, authentication, data integrity, asynchronous work, and failure handling.

My primary development paths are Python with FastAPI and TypeScript with Node.js/Express, backed by relational databases and supporting infrastructure such as Redis and Docker. I value systems that are understandable to the next engineer—not just systems that work on the happy path.
